# Pharmacy Inventory Management System

A Pharmacy Inventory Management System built with Laravel 12.

## Overview

This application helps pharmacies manage inventory, purchases, sales, suppliers, customers, and reports from one system.

## Features

- User Authentication
- Dashboard
- Medicine Management
- Categories
- Suppliers
- Customers
- Purchases
- Sales
- Receipt Printing
- Reports

## Technologies

- Laravel 12
- PHP
- MySQL
- Blade
- Bootstrap

## Installation

1. Clone the repository
2. Run composer install
3. Configure .env
4. Run php artisan migrate
5. Run php artisan serve
